# 무지개장미탐험대 퀴즈

서울시립과학관(SSC)의 오프라인 행사에서 진행하는 **무지개장미탐험대** 컨셉의 퀴즈 웹앱입니다. 참가자들이 정해진 순서대로 과학 전시물을 둘러보며, 각 전시물과 관련된 과학 퀴즈를 모바일 화면에서 풀어 나갑니다.

## 흐름

1. **시작 화면** → 안내 화면
2. **전시물 한눈에 보기** → 오늘 둘러볼 전시물 미리보기
3. 각 전시물마다:
   - **이동 안내** (다음 전시물 코드/위치)
   - **퀴즈** (객관식 또는 단답식)
4. **클리어 화면**

전시물·퀴즈 데이터는 [`src/data.ts`](src/data.ts)에서 관리합니다.

## 기술 스택

- React 18 + TypeScript
- Vite
- Tailwind CSS 3

모바일 한 손 사용에 맞춰 `max-w-md` 단일 컬럼 레이아웃으로 구성되어 있습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```

## 주요 디렉터리

```
src/
├── App.tsx                 # 화면 흐름 제어
├── data.ts                 # 전시물 / 퀴즈 데이터
├── types.ts
└── components/             # 화면별 컴포넌트
public/assets/              # 전시물 이미지 등 정적 에셋
```
