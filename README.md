# 블루미 GO!

서울시립과학관(SSC) B전시실의 오프라인 행사에서 진행하는 **블루미 GO!** 교통 활동지 웹앱입니다. 참가자들이 자전거 → 셔틀버스 → 버스/지하철 → 지하철 → 배 순서로 교통 전시물을 찾아다니며, 각 교통수단 속 과학 퀴즈를 모바일 화면에서 풀어 나갑니다. 모든 퀴즈를 해결하면 특별한 목적지(관천대)가 공개됩니다.

## 흐름

1. **시작 화면** → **초대장**
2. **블루미의 이동 경로** → **활동지 이용안내**
3. 각 교통수단마다:
   - **이동 안내** (전시물 사진/코드)
   - **퀴즈 2개** (객관식 / OX / 단답식 / 숫자 입력식)
   - **퀴즈 완료 팝업** (Great job!)
4. **퀴즈 클리어** → **목적지 공개** (B28 관천대)

전시물·교통수단·퀴즈 데이터는 [`src/data.ts`](src/data.ts)에서 관리합니다.

## 기술 스택

- React 18 + TypeScript
- Vite
- Tailwind CSS 3

모바일 한 손 사용에 맞춰 `max-w-md` 단일 컬럼 레이아웃으로 구성되어 있습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

배포는 `dist/` 폴더를 정적 호스팅(Netlify 등)에 업로드하면 됩니다.

## 주요 디렉터리

```
src/
├── App.tsx                 # 화면 흐름 제어
├── data.ts                 # 전시물 / 교통수단 / 퀴즈 데이터
├── types.ts
└── components/             # 화면별 컴포넌트
public/assets/              # 전시물 사진, 배치도 등 정적 에셋
```
